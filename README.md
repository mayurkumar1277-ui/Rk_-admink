# RK ADMIN
Offline Android admin dashboard starter project.

## Login
Default PIN: `1234`

## Features
- PIN login
- Dashboard and user count
- Add and delete local users
- Basic reports
- Settings screen

## Build APK
Open this folder in Android Studio (JDK 17, Android SDK 35), sync Gradle, then Build > Build APK(s).

Or upload the project to a GitHub repository. The included GitHub Actions workflow builds a debug APK on push or manual run. Download `app-debug.apk` from the workflow run's Artifacts.

This app stores demo data locally on the device. It is not connected to a server or another app.
